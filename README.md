# Moses Milambo - Interactive Personal Website

ICT251 Web Technologies, Activity 3, Mulungushi University.

A responsive personal portfolio built with HTML5, CSS and JavaScript. It has About Me, Hobbies, Learning Plan, Projects, Photos, Media (video and audio) and Contact sections.

## JavaScript features (js/script.js)

1. *Contact form validation and preview:* Rejects empty or spaces-only name and message, and badly formatted email. A valid form shows a local summary. It is a browser demonstration only, and no message is sent.
2. *Gallery viewer:* Previous and Next buttons change the photo and its caption. The buttons are disabled on the first and last photo.
3. *Theme switch:* Toggles between light and dark mode. The choice is saved in the browser.
4. *Mobile navigation:* On narrow screens, a Menu button opens and closes the navigation links.

## How to test

- *Contact form:* submit it empty, then with spaces only, then with an invalid email such as abc, then with valid details.
- *Gallery:* click Next to the last photo and Previous back to the first. The buttons disable at the ends.
- *Theme:* click the theme button and check the text stays readable. Reload the page to see the choice remembered.
- *Mobile menu:* make the browser narrower than 700px, then open and close the menu.
